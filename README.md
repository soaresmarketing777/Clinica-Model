# 🏥 Clínica Model - Site Profissional Completo

Site completo, responsivo e otimizado para conversão, desenvolvido com HTML5, CSS3 e JavaScript puro (ES6+).

## 📋 Stack Tecnológica

- **HTML5** semântico com Schema.org LocalBusiness
- **CSS3** moderno (variáveis, grid, flexbox, glassmorphism, dark mode)
- **JavaScript ES6+** puro (Intersection Observer, LocalStorage, UTM tracking)
- **Hospedagem estática** (GitHub Pages, Netlify, Vercel)
